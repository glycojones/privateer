Tool: Privateer - Validate Carbohydrates

The Privateer tool can be used to visualise and validate carbohydrates within the structure.

The tool displays a drop down menu to select the model you want to run Privateer on. There is a button to Run Privateer which produces a validation report of glycans in the structure. This check sugar ring conformations and linkage torsion angles within the glycan, and searches for the glycan in well-known glycan databases, displaying the ID if found.

It also produces an interactive SNFG visualisation of the glycan. Sugars in unlikely ring conformations are highlighted. Linkages which are torsion outliers (compared to Privateer's torsion database) are highlighted. Clicking on a sugar will center Chimeraq X's view on that sugar. Clicking on a linkage will display a torsion plot of that linkage, overlayed with data from Privateer's torsion database.

UCSF Resource for Biocomputing, Visualization, and Informatics / February 2019
